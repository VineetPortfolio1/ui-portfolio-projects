# UI portfolio: projects

Static pages, no build step. Open `index.html` in a browser.

- `index.html`: project cards for 12 client websites and 3 concept designs, with category filters and search
- `tamarind-lane.html`: concept site for a fictional coffee roaster (brew calculator, subscription total)
- `ledgerline.html`: concept marketing site for a fictional invoicing product (90-day cash forecast, pricing switch)
- `hollis-rao.html`: concept site for a fictional architecture studio (scaled floor plans, project explorer)

The three concept brands are fictional and made for portfolio purposes. Fonts load from Google Fonts.
